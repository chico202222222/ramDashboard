<h1 style="font-size:24px; font-weight:bold;">INTRODUCTION</h1>
hello!
This is a simple application, where I coded in Python so you can 
have a simple lightweight dashboard that tracks your RAM usage from
  0% to 100%!

thank you for using :)


  

<h1 style="font-size:24px; font-weight:bold;">REQUIREMENTS</h1>
- python 3.8 or higher
- psutil library (for monitoring RAM usage)
- pandas (for data manipulation, saving to a .json, min max etc)
- matplotlib (the "core" of the whole code, that plots the RAM usage onto a graph)
- tk (for the GUI, the dashboard itself)
- datetime, os, time (for various functionalities, like saving the data, getting the current time etc, but those are built-in libraries, so you don't need to install them)

<h1 style="font-size:24px; font-weight:bold;">INSTALLATION</h1>
          1. download as a .zip/clone the repository
          2. make sure the libraries are installed properly and loading correctly.
          3. open main.py with an IDE
          (MAKE SURE that all the other files are in the same folder as the main.py, otherwise it won't work.)
          4. Run the code
